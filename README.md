Solmar — Streets of Solmar: an original open-world crime game in the browser. Explore a sun-soaked coastal city on foot or by car, steal rides, outrun the Solmar PD as your wanted level climbs, and run story missions for fixer Vera Cruz — pickups, getaways, fares and one big score — with a live minimap, HUD, save system and synthesized sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — everything the game loads is a file under `game/`.
